<h1 align="center">Electron Spark Boilerplate</h1>

<p align="center">A starting point for your next desktop app, built with Electron Spark, React, and TypeScript.</p>

Clone the project, install dependencies, and start building your app. This boilerplate uses [Electron Spark](https://github.com/cahnory/electron-spark) to connect Electron's main process, preload, and renderer through a shared Vite configuration, with examples of typed IPC and persistent settings already wired up.

## Get started

Use **Node.js 24 or newer** and **pnpm**.

```sh
git clone https://github.com/cahnory/electron-spark-boilerplate.git my-app
cd my-app
pnpm install
pnpm dev
```

The development command starts Vite and opens the Electron app. Edit the source files to begin developing, with hot updates for the React UI.

## What's included

- **Electron Spark** — Vite configuration, app identity, typed IPC, versioned storage, and packaging verification.
- **React** — a component-based desktop UI with hot updates during development.
- **TanStack Router** — file-based routing for the React UI.
- **vanilla-extract** — styles written in TypeScript.
- **Internationalization** — React Intl with locale message files and a persisted language preference.
- **Settings example** — Zod validation, file-backed storage, and state subscriptions across the main process and UI.
- **Development checks** — formatting with Oxfmt, linting with Oxlint, type checking, Node.js tests, and unused-code checks with Knip.
- **Packaging** — electron-builder configuration, platform icons, and release verification hooks.

## Make it yours

1. Update the name, version, author, and repository in [package.json](./package.json).
2. Set your app's `appId` and `productName` in [electron-builder.json](./electron-builder.json).
3. Replace the icons in `src/resources/icons/` and the favicon in `src/public/`.
4. Delete the `src/view/routes/_electron-spark/` demo group and create `src/view/routes/index.tsx` as your app's home screen. Add your other routes alongside it.
5. Adapt [src/main/settings.ts](./src/main/settings.ts) and [src/view/preload.ts](./src/view/preload.ts) for your app's stored data and IPC actions.

## Project structure

```text
src/
  main/          Electron startup, window management, security, and settings
  view/          React UI, routes, styles, translations, and preload entry
  public/        Static assets for the renderer
  resources/     Application resources copied into the main-process output
scripts/         Packaging hooks and test reporter
tests/           Tests for lifecycle, security, settings, and release behavior
vite.config.ts   Electron Spark and renderer plugin configuration
```

Window options live in [src/view/window.json](./src/view/window.json). Translation messages live in `src/view/messages/`. Files named `*.generated.ts` are generated by the build tooling.

For additional windows, add views under `src/views/`, each in its own folder following the same structure as `src/view/` (for example, `src/views/settings/`). Electron Spark discovers both `src/view/` and `src/views/*/`, so each window can have its own UI, preload entry, and window options.

For files needed by the main process, use `src/resources/` and access them through `RESOURCES_PATH` from `src/main/constants.ts`. See the [resources guide](./src/resources/README.md) for details.

## Commands

| Command            | Purpose                                                                      |
| ------------------ | ---------------------------------------------------------------------------- |
| `pnpm dev`         | Start the Electron app in development mode.                                  |
| `pnpm check`       | Run formatting, lint, test, type, and unused-code checks.                    |
| `pnpm fix`         | Apply unused-code, lint, and formatting fixes. Review the resulting changes. |
| `pnpm build:dist`  | Compile the app into `dist/`.                                                |
| `pnpm build:local` | Run checks and create an unpacked app for local testing.                     |
| `pnpm build`       | Run checks, compile, and package release artifacts.                          |

## Build your app

For an unpacked build to try locally:

```sh
pnpm build:local
```

Output goes to `release/local/<version>/`. The local configuration disables mandatory code signing and macOS notarization, and uses ad hoc signing on macOS.

For release artifacts:

```sh
pnpm build
```

Output goes to `release/<version>/`. The release configuration requires code signing and enables macOS notarization. Configure your signing credentials and review [electron-builder.json](./electron-builder.json) and [scripts/release-hooks.ts](./scripts/release-hooks.ts) before distributing your app. Both build commands disable automatic publishing.
